# Seed Data (`data/seed`)

Contains the generated seed datasets: real book metadata from Open Library (`books-openlibrary.json`) and
100% synthetic members, librarians, copies, loans, fines, and reservations. Real personal data is strictly prohibited.

Sources, regeneration commands, file formats, assumptions, and the Open Library license are documented in
[`../README.md`](../README.md). These JSON files are machine-generated; do not edit them by hand.
